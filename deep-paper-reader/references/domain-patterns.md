# Domain Patterns：AI/机器学习论文的自适应精读

> 在建立 Paper Map 之后使用。根据实际论文贡献类型，选择 1–3 个主要分析视角，不把所有领域特定问题套在单篇论文上。

## 1. 方法类型路由

| 主要论文类型 | 第一优先内容 | 常见核查点 |
|---|---|---|
| 新网络架构 | 结构图、张量流、模块功能、训练/推理 | 维度、参数共享、残差、效率 |
| 新优化目标/训练方法 | Objective、采样、梯度、优化变量 | 公式假设、负样本、收敛、额外预算 |
| 预训练/微调/对齐 | 数据、损失、阶段划分、更新参数 | 数据污染、训练/推理目标不一致 |
| 理论分析 | 假设、定理、证明、定理支持的结论 | 充分条件与实际网络之间的距离 |
| 推理或解码加速 | 推理步骤、缓存、吞吐/延迟 | 质量-速度权衡、batch/硬件条件 |
| 新 benchmark/评估 | 任务构造、标注、数据切分、指标 | 数据泄漏、评估偏差、有效性 |
| 系统工程 | 系统边界、调度、资源优化、可靠性 | 瓶颈定位、负载条件、资源成本 |
| 稀疏/正则化模型 | 优化问题、正则项结构、求解器 | 组结构依据、收敛、超参选择、可解释性证据 |
| 生理信号/BCI 解码 | 数据范式、预处理、时空频特征、评估协议 | 被试内/跨被试、时间相关泄漏、每被试方差 |

可以为混合论文选择多个视角，但需明确哪项是作者主要贡献。

## 2. Transformer / 语言模型

必要时核查：
- tokenizer、embedding、位置/相对位置编码、attention mask、Q/K/V 的形状与位置。
- self/cross attention、MoE、FFN、normalization、residual 的先后顺序是否由原图明确给出。
- 训练目标（next-token、masked、contrastive、preference 等）和推理解码是否对应。
- 长上下文、KV cache、稀疏注意力、GQA/MQA 之类效率设计是否真的在文中出现。
- 预训练、SFT、reward modeling、DPO、RLHF、量化、蒸馏等阶段的不同优化对象。
- 在复杂 LLM 评估中关注 benchmark contamination、prompt 与解码配置、pass@k 等协议。

**不要**因为论文本身是 Transformer 就自动宣称使用 RoPE、flash attention、MoE 或 RLHF。

## 3. 计算机视觉与多模态

- 识别 backbone、visual/token encoder、fusion 模块、decoder、任务头。
- 跟踪图片/视频 patch 大小、分辨率、帧数、token 数、下采样与上采样。
- 说明跨模态对齐是 contrastive、cross-attention、projection 还是其他机制。
- 检查训练图文配对质量、标注来源、负样本采样、模态缺失的影响。
- 评估时关注不同模态的 benchmark、公平使用预训练数据、分辨率对性能和成本的影响。

## 4. 扩散、流模型与生成建模

- 分离正向过程、反向过程、噪声调度、score/noise/data prediction、训练 loss 与采样算法。
- 不混淆 diffusion step、训练 step 与实际函数调用次数。
- 明确随机变量分布、条件变量、时间参数化和独立性假设。
- 如果提到 ELBO、ODE/SDE、flow matching、classifier-free guidance，指出其在这篇论文的具体用法。
- 检查生成质量、采样开销、图像尺寸、样本量及 FID/KID 等指标定义。

## 5. 强化学习与序列决策

- 建立状态/观测、动作、策略、价值/奖励、轨迹、折扣率的对应表。
- 区分 on-policy、off-policy、offline RL 和基于模型的方法。
- 对 policy gradient、value backup、actor-critic、优势估计明确采样分布和更新目标。
- 审查训练环境交互预算、随机种子数量、评估回报分布与安全性约束。
- 不把单环境平均回报提升当成跨环境泛化。

## 6. 图神经网络 / 表示学习

- 定义图节点、边、邻域、消息传递、读出、异构/动态结构。
- 检查 message passing 步数、局部/全局信息、过平滑与计算复杂度主张。
- 对对比学习明确正负样本构建、增强方式、temperature 和损失对象。
- 审查数据集拆分（transductive/inductive）、节点泄漏或跨图泛化。

## 7. 检索增强与工具使用（RAG / Agents）

- 区分索引构造、检索器、重排序、提示构建、生成器、工具/环境反馈。
- 说明训练时是否依赖 oracle docs、推理时是否可以访问相同信息。
- 评估时区分 retrieval quality、answer quality、citation faithfulness、tool success 和 cost。
- 不因生成文本带引用就认定引用真实或事实正确；核查证据检索及引用范围。
- 用户要求无外部知识库连接时，**不得擅自连第三方文献库或私有知识库**；论文中使用 RAG 属于被分析的方法，而非 Skill 自己调用外部库。

## 8. 理论论文与数学证明

- 定义定理成立的完整前提（损失平滑、convexity、distributional assumption、model capacity、优化误差等）。
- 将引理—定理—推论—实验的逻辑链拆开；说明定理究竟保证何种性质。
- 区分全局最优、局部最优、收敛到驻点、界的松紧与有限样本条件。
- 如果证明仅在附录且附录不可得，不能描述为“已独立核实证明”。
- 反例讨论必须明确是假设内还是假设外。

## 9. 经典统计学习、稀疏建模与凸优化

适用于 LASSO / Group LASSO / Sparse Group LASSO、低秩、核方法、SVM、图正则、字典学习等“模型 + 正则 + 求解器”型论文。

- 先写出完整优化问题：数据拟合项、正则项、约束、各超参数（$\lambda$、$\alpha$ 等），并说明每一项“想让解长成什么样”（稀疏、组稀疏、平滑、低秩）。
- 组结构从哪里来：分组是按通道、频带、脑区、特征类型，还是学习得到？分组是否重叠？组权重（如 $\sqrt{p_g}$）怎样设置？这往往就是论文的主要创新点。
- 讲清正则项的几何直觉（L1 球的尖角产生稀疏；组范数让整组同时为零），并配一个 2–3 维的小例子。
- 求解器：近端梯度 / ISTA / FISTA、坐标下降、ADMM、块坐标下降等。说明近端算子（如组软阈值）的闭式形式、收敛条件、步长选择；论文自己推导的更新式逐行对照讲解。
- 区分凸 / 非凸、全局最优 / 驻点，以及理论保证（恢复条件、误差界）的前提是否被实际数据满足。
- 超参数选择：交叉验证怎么做、是否在测试数据上调参、正则路径是否报告。
- 可解释性主张：“选出的特征/区域有意义”通常需要稳定性分析（不同折、不同被试是否选出相同的组）或与先验知识对照，单次可视化不足以证明。

## 10. 脑机接口、EEG 与生理信号解码

适用于运动想象（MI）、P300、SSVEP、情绪识别、睡眠分期、EMG/ECG 等信号解码论文，以及时空图模型在这类数据上的应用。

- **数据与范式**：数据集（如 BCI Competition IV 2a/2b、OpenBMI、PhysioNet MI 等，以论文所述为准）、被试数、通道数与电极布局、采样率、试次长度与时间窗、类别数。
- **预处理链**：滤波频带、重参考、伪迹去除（ICA 等）、降采样、通道选择、欧氏对齐/数据对齐。每一步都可能影响结果，记录论文是否报告。
- **特征与模型**：CSP/FBCSP、黎曼几何（协方差矩阵、切空间）、时频特征、EEGNet/ShallowConvNet 类 CNN、图神经网络（电极图如何构建：物理距离、功能连接、可学习邻接矩阵）。说明空间、频谱、时间三个维度分别由哪个模块处理，输入张量通常是 $C\times T$ 或 $C\times F\times T$。
- **区域/通道结构**：按脑区分组（如运动皮层 C3/Cz/C4 周围）的依据是什么？分组是先验固定还是学习得到？与神经生理学先验的对应只能作为一致性证据，不等于因果证明。
- **评估协议（最关键）**：被试内（within-subject）还是跨被试（cross-subject / leave-one-subject-out）？是否跨 session？划分是否按试次随机打乱导致同一 session 的相邻数据同时出现在训练和测试中（时间相关性泄漏）？预处理或特征选择是否在划分前用了全部数据？
- **指标**：accuracy、Cohen's kappa、ITR（信息传输率，依赖试次时长与类别数）、F1；被试间差异大，应关注每被试结果与标准差，而不只看平均值。
- **对比公平性**：基线是否用同一数据集、同一划分、同一时间窗和预处理；复现的基线数值与原论文报告值是否一致。
- **结论边界**：少量被试上的提升、单一数据集结果、离线分析结论不能直接推广到在线 BCI 或其他范式。

## 11. 时序与通用信号建模

- 明确采样率、窗口长度、步长、预测时域；窗口是否重叠以及重叠窗口是否跨越训练/测试划分。
- 归一化统计量是否只用训练集计算。
- 频域与时域方法的对应关系（卷积核大小 ↔ 频率分辨率）。

讲解深度（beginner / intermediate / expert）的调节方法见 `teaching-playbook.md` §2。
